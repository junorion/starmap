# Starmap 안드로이드 앱

[PRODUCT.md](../../../PRODUCT.md)의 하늘지도를 안드로이드 앱으로 설치해 쓸 수 있게 하는 첫 작업 단위입니다. 이후 AR 모드(카메라로 하늘을 비추기)를 앱에서 만들기 위한 바탕이 됩니다. 기존 [기본 하늘지도 스펙](../starmap-sky-chart/spec.md)의 동작은 그대로 두고, 앱으로 감싸는 것과 휴대폰 화면 배치만 다룹니다.

## 사용자에게 보이는 결과

1. 안드로이드 폰에 APK 를 설치하면 "Starmap" 아이콘이 생기고, 누르면 인터넷 연결 없이 하늘지도가 화면 전체에 뜬다.
2. 처음 열 때 위치 권한을 묻고, 허용하면 현재 위치 기준으로, 거부하면 지금처럼 서울 기준으로 그린다.
3. 앱에서는 폰이든 태블릿이든, 세로든 가로든 제목 없이 지도가 화면 전체를 채운다.
4. 폰 브라우저로 웹을 열어도 같은 전체 화면 배치로 보인다. 데스크톱 웹 화면은 지금과 같다.

## 범위

**포함**
- 정적 내보내기: Next.js 를 `output: "export"` 로 빌드해 `out/` 에 정적 파일로 만든다. 서버 기능을 쓰지 않으므로 동작은 바뀌지 않는다.
- 전체 화면 배치(Tailwind 사용자 정의 변형 `fullscreen`): 화면 폭 640px 미만(휴대폰)이거나, **안드로이드 앱 안**일 때 적용한다. 앱은 user agent 에 `StarmapAndroid/` 를 붙이고, 웹은 첫 화면을 그리기 전에 인라인 스크립트로 `<html data-shell="app">` 을 단다. 그래서 태블릿처럼 넓은 화면의 앱에서도 같은 배치가 된다(2026-10-29 태블릿 확인 후 사용자 요청).
  - 페이지 제목과 소개 문구는 화면에서 숨기고(스크린 리더에는 남긴다) 바깥 여백을 없앤다.
  - 9:19.5 휴대폰 모양 틀 대신 지도 화면이 기기 화면 전체(`100dvh`)를 채운다. 둥근 모서리는 없다.
  - 위치·시각 줄은 상태 표시줄 영역을, 오른쪽 아래 버튼과 팝업은 내비게이션 바 영역을 피한다(`env(safe-area-inset-*)`).
  - 앱 밖에서 640px 이상(데스크톱·태블릿 브라우저)은 지금 배치(제목, 9:19.5 틀, 최대 폭 390px)를 그대로 쓴다.
- 안드로이드 뒤로 가기: 가운데 창(옵션, 찾기, AR 안내, 돌리기 안내)이 열려 있으면 그 창을 닫고, 없고 별자리 팝업이 열려 있으면 팝업을 닫는다(선택도 풀린다). 둘 다 없으면 앱을 닫는다.
- 안드로이드 래퍼(`android/`)
  - [app_development 템플릿](https://github.com/junorion/app_development)의 WebView 래퍼를 바탕으로 한다.
  - `out/` 을 앱 자산으로 담고, `https://appassets.androidplatform.net/` 주소로 내준다(`WebViewAssetLoader`). `/_next/…`, `/data/…` 같은 루트 경로 요청이 그대로 동작하고, https 라서 위치 API 를 쓸 수 있다.
  - 위치 권한: 웹이 위치를 요청하면 안드로이드 위치 권한(대략·정확)을 묻고, 결과를 웹에 그대로 돌려준다.
  - 앱 자산 밖의 주소로는 이동하지 않는다. 인터넷 권한은 없다.
  - 화면은 상태 표시줄을 숨긴 전체 화면이고, 회전해도 지도 상태가 유지된다.
  - 앱 아이콘은 밤하늘의 별자리 모양이다(`android/icon/icon.html`).

**이번에 하지 않을 것:** AR 모드, Play 스토어 출시(서명 키·스토어 자료), iOS, 가로 화면 전용 배치, 오프라인 웹(PWA·service worker), 마우스 조작 정리

## 인수 기준

- `bun run build` 가 `out/index.html` 과 `out/data/*.json` 을 만들고, 기존 테스트가 모두 통과한다.
- 폭 390px 화면에서 페이지 제목이 보이지 않고 지도 화면이 화면 전체를 채운다. 폭 1024px 화면은 지금과 같다(제목, 9:19.5 틀).
- user agent 에 `StarmapAndroid/` 가 있으면 폭 800px(세로)·1200px(가로)에서도 제목 없이 지도가 화면 전체를 채운다.
- (실기기) 태블릿 앱에서 제목과 휴대폰 모양 틀이 보이지 않고, 세로·가로 모두 지도가 화면 전체를 채운다.
- 옵션 창을 연 상태에서 뒤로 가기 훅(`window.onAndroidBack()`)을 부르면 `true` 를 돌려주고 창이 닫힌다. 별자리를 선택한 상태에서 부르면 `true` 를 돌려주고 팝업이 닫힌다. 아무것도 없으면 `false` 다.
- `android/` 에서 `./gradlew assembleDebug` 로 APK 가 만들어지고, 패키지는 `com.junorion.starmap`, targetSdk 36, 자산에 `index.html`·`_next/`·`data/` 가 들어 있다.
- (실기기) 설치 후 비행기 모드에서도 하늘지도가 뜬다.
- (실기기) 위치 권한을 허용하면 위치 줄에 "현재 위치"가, 거부하면 "서울 (위치를 확인하지 못해 기본값 사용)"이 보인다.
- (실기기) 한 손가락 이동, 두 손가락 핀치·돌리기, 별자리 선택이 된다. 위치 줄과 오른쪽 아래 버튼이 시스템 바에 가리지 않는다.
- (실기기) 옵션 창이나 팝업이 열린 상태에서 뒤로 가기를 누르면 그것만 닫히고, 아무것도 없을 때 누르면 앱이 닫힌다.

## 확정된 제약과 근거

- **변환 방식은 정적 내보내기 + WebView 래퍼다.** 사용자가 확정했다. 지금 코드와 테스트를 그대로 쓰고, Capacitor 처럼 도구를 더하거나 Flutter 로 다시 쓰지 않는다. 카메라와 방향 센서도 WebView 권한 연결로 쓸 수 있어서 AR 때문에 방식을 바꿀 필요는 없다.
- **웹 소스는 하나다.** 안드로이드는 빌드할 때 `out/` 을 복사해 쓰고 사본을 커밋하지 않는다.
- **웹 런타임 검증은 헤드리스 Chrome 스크린샷으로 한다.** 이 개발 환경(WSL2)에는 `agent-browser` 와 화면이 있는 브라우저가 없어 `next-dev-loop` 를 쓸 수 없다.

## 가정 (에이전트가 정한 값, 바꿀 수 있음)

- 패키지명 `com.junorion.starmap`, 앱 이름 "Starmap". 패키지명은 Play 에 올린 뒤 못 바꾸므로 출시 전에 다시 확인한다.
- 휴대폰 배치 기준은 640px(Tailwind `sm`)이다.
- 별을 보는 동안 화면이 꺼지지 않게 앱에서는 화면 꺼짐을 막는다.

## 남은 위험

- **위치 시간 초과:** 실내에서 위치를 처음 잡는 데 10초(`GEOLOCATION_TIMEOUT_MS`)를 넘기면 권한을 허용해도 서울로 대체된다. "현재 위치로" 버튼으로 다시 받을 수 있다.
- **실기기 확인:** 이 환경에는 에뮬레이터가 없어서 설치·권한·터치·뒤로 가기는 실기기에서만 확인된다.
- **창 크기 변화:** 회전하면 지도 크기가 바뀌는데, `docs/follow-ups/pan-not-clamped-on-resize.md` 의 이동 범위 문제가 이때 드러날 수 있다.
